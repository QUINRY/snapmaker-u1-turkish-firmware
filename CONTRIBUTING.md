# Contributing

Contributions that improve Turkish wording, layout fit, validation or documentation are welcome.

## Rules

1. Work against one exact firmware version. Do not copy strings from another version.
2. Preserve JSON keys, ordering, placeholders, technical tokens, numbers and intentional line breaks.
3. Use UTF-8 without BOM and NFC-normalized Turkish characters.
4. Keep the Stock and Extended channels separate.
5. Do not commit original firmware, modified firmware, extracted root filesystems, proprietary GUI binaries, credentials, device configuration or other vendor assets.
6. State whether the change was structurally validated and whether it was tested on a physical printer.
7. Include updated hashes when a tracked translation or manifest changes.

By submitting a contribution, you confirm that you have the right to provide your contribution under `GPL-3.0-only`. This does not change the terms that apply to third-party material.
